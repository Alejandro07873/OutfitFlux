# Credits and external components

OutfitFlux builds on the MHUR Model Swapper project by XShawolf. Preserve upstream attribution when editing or publishing the code.

External projects used in the workflow:

- [MHUR Model Swapper](https://github.com/XShawolf/MHUR-Model-Swapper) — original application base.
- [UAssetAPI](https://github.com/atenfyr/UAssetAPI) — Unreal asset read/write library used by the bundled conversion workflow.
- [repak](https://github.com/trumank/repak) — PAK inspection and extraction.
- [UE4-DDS Tools](https://github.com/matyalatte/UE4-DDS-Tools) — thumbnail conversion.
- [FFmpeg](https://ffmpeg.org/) — conversion fallback.
- UnrealPak — Unreal Engine packaging utility.
- [PySide6](https://doc.qt.io/qtforpython-6/) — Qt user interface.

The prepared source folder does not bundle these tools. Their own licenses and redistribution requirements apply to any binary release. The original workspace did not provide a top-level license for the application; no replacement license has been fabricated. Retain notices from the exact dependency distributions used for your release.

Game names and game imagery belong to their respective owners. OutfitFlux is an independent community tool.
