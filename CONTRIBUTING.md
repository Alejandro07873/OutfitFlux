g# 🤝 Contributing

Start with [Development](docs/DEVELOPMENT.md). Keep UI text available in English and Spanish, preserve the original mod and test output paths with the source and destination in different folders.

Before submitting:

- Run `python -m unittest discover -s tests`.
- Include screenshots for visual changes in both themes.
- Describe how the behavior changed and what you tested.
- Keep game data, personal configuration, mod files and tool binaries out of source commits.
- Preserve upstream attribution and dependency notices.
