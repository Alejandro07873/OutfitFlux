# Changelog

## 1.1.5

- Re-exported filenames replace previous catalog-recognized costume names in English or Spanish instead of accumulating them.
- Preserves mod prefixes, author attribution, unrelated tags and collision counters.
- Handles costume names containing parentheses and punctuation variations.
- Adds a Spanish publishing guide for maintainers.

## 1.1.4

### Fixed
- Batch exports now honor the selected output folder when the imported mod uses an absolute path.
- Single-destination review follows the same folder workflow as multi-destination export.
- Tool categories and queue labels update when the interface language changes.

### Improved
- Costume workspace with a dedicated right-side mod card and more vertical room.
- Per-costume queue previews, individual stage progress and an import action for the empty queue.
- Visual export review with thumbnails and grouped folder options.
- Tools with category navigation and structured result views.
- Animated neon wordmark with a gradient moving inside the letters.
- Catalog update action directly in the costume workspace.
- English repository documentation, editable banner and screenshot resources.

## 1.1.3

- Incremental asset preparation and cached web catalog updates.
- iOS-inspired dark/light themes and configurable accents.
- Background export queue and configurable GitHub Releases updates.
